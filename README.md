Git — система контроля версий
Какие задачи решает Git?
Git — это распределённая система контроля версий, которая помогает разработчикам управлять изменениями в программном коде и других файлах проекта.
Git решает следующие задачи:
Контроль версий — сохраняет историю изменений файлов.
Совместная работа — позволяет нескольким разработчикам работать над одним проектом.
Возврат к предыдущим версиям — помогает восстановить старое состояние проекта, если были допущены ошибки.
Работа с ветками — позволяет разрабатывать новые функции отдельно от основного кода.
Объединение изменений — помогает объединять работу разных разработчиков.
Отслеживание изменений — показывает, кто, когда и какие изменения внёс в проект.
Что такое ветки и коммиты?
Ветки (Branches)
Ветка — это отдельная линия разработки проекта.
Ветки позволяют работать над новыми функциями, исправлять ошибки и экспериментировать, не изменяя основной код проекта.
Основная ветка обычно называется main или master.
Например:
main — основная версия проекта.
feature — ветка для разработки новой функции.
bugfix — ветка для исправления ошибок.
После завершения работы ветки можно объединить с основной веткой.
Коммиты (Commits)
Коммит — это сохранённый набор изменений в репозитории Git.
Каждый коммит содержит:
Уникальный идентификатор.
Информацию об авторе.
Дату и время создания.
Описание внесённых изменений.
Сохранённое состояние файлов проекта.
Коммиты позволяют просматривать историю разработки и при необходимости возвращаться к предыдущим версиям проекта.
Пример команды создания коммита:
git add .
git commit -m "Добавлен README.md"
Вывод
Git — важный инструмент для разработки программного обеспечения. Он помогает контролировать версии проекта, сохранять историю изменений, работать в команде и безопасно разрабатывать новые функции.
